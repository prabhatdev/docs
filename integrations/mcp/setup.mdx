## Executive MCP Server Integration

MCP servers enable Dume to connect with specialized business tools, proprietary systems, and strategic intelligence platforms beyond standard integrations. Perfect for executives who need custom competitive intelligence, unique market analysis tools, or specialized business automation that standard integrations can't provide.

**When to Use MCP:** When you need integration with business tools not available in Dume's standard integration library - from proprietary competitive intelligence platforms to specialized strategic planning systems.

## Quick MCP Server Setup for Executives

<Steps>
    <Step title="Access MCP Integration">
        Navigate to MCP servers section in your Dume.ai executive dashboard.
    </Step>
    <Step title="Add Executive Integration">
        <img
            src="/images/Screenshot2025-07-08at12.01.03AM.png"
            alt="MCP Server Setup Interface"
            title="MCP Server Setup"
            style={{ width:"78%" }}
        />
        Click "Add Server" to connect specialized business intelligence tools.
    </Step>
    <Step title="Choose Integration Protocol">
        Select SSE or HTTP based on your business system requirements.

        <img
            src="/images/Screenshot2025-07-08at12.01.56AM.png"
            alt="Screenshot2025 07 08at12 01 56AM Pn"
            title="Screenshot2025 07 08at12 01 56AM Pn"
            style={{ width:"66%" }}
        />
    </Step>
    <Step title="Configure Business Intelligence">
        Enter strategic system details: server name, URL, and business intelligence description.

        <img
            src="/images/Screenshot2025-07-08at12.04.24AM.png"
            alt="Screenshot2025 07 08at12 04 24AM Pn"
            title="Screenshot2025 07 08at12 04 24AM Pn"
            style={{ width:"63%" }}
        />
    </Step>
    <Step title="Add MCP Server">
        Click Add Server and wait for [Dume.ai](http://Dume.ai) to connect to the server. Once added, Dume ai will call the MCP server automatically whenever required.
    </Step>
    <Step title="Test MCP server">
        Once connected, you can test the MCP servers and it should show the MCP server as connected.

        ![Screenshot 2025-07-20 at 3.57.49 PM.png](/images/Screenshot2025-07-20at3.57.49PM.png)

        You can also click on view view tools to see the supported tools the MCP server supports.

        <img
            src="/images/Screenshot2025-07-20at4.03.09PM.png"
            alt="Screenshot 2025-07-20 at 4.03.09 PM.png"
            style={{ width:"100%" }}
        />
    </Step>
    <Step title="Check out the tools the MCP server supports">
        Clicking on view tools will show you the dialog with the list of tools supported by the MCP server. Go through the tools and it'll help you understand the strengths and limitations of the MCP server.

        ![Screenshot 2025-07-20 at 4.07.28 PM.png](/images/Screenshot2025-07-20at4.07.28PM.png)
    </Step>
    <Step title="Use the MCP server">
        ![Screenshot 2025-07-20 at 4.00.32 PM.png](/images/Screenshot2025-07-20at4.00.32PM.png)
    </Step>
    <Step title="Response from MCP server">
        Once connected, you can easily ask the MCP server for any request directly from chat.\
        **Example**- Can you write a linkdIn post on how MCP servers with AI are great for crypto startups.

        ![Screenshot 2025-07-20 at 11.54.26 PM.png](/images/Screenshot2025-07-20at11.54.26PM.png)
    </Step>
</Steps>
