## Quick MCP Server Setup for Executives

<Steps>
    <Step title="Access MCP Integration">
        Navigate to MCP servers section in your Dume.ai sidebar.
    </Step>
    <Step title="Add Executive Integration">
        Click "Add Server" to connect specialized business intelligence tools.

        <Frame>
    <img
        className="block dark:hidden"
        src="/images/light/integration/mcp/add_first_server.png"
        alt="MCP Server Setup Interface"
        title="MCP Server Setup"
    />
    <img
        className="hidden dark:block"
        src="/images/dark/integration/mcp/add_first_server.png"
        alt="MCP Server Setup Interface"
        title="MCP Server Setup"
    />
</Frame>
    </Step>
    <Step title="Choose Integration Protocol">
        Select SSE or HTTP based. MCP servers starring with *sse://* are SSE and the ones starting with *https://* are HTTP streamable mcp server.

       
         <Frame>
    <img
        className="block dark:hidden"
        src="/images/light/integration/mcp/add_mcp_type.png"
        alt="MCP choose protocol"
        title="MCP choose server type"
    />
    <img
        className="hidden dark:block"
        src="/images/dark/integration/mcp/add_mcp_type.png"
        alt="MCP choose protocol"
        title="MCP choose server type"
    />
</Frame>
    </Step>
    <Step title="Configure Business Intelligence">
        Enter MCP server details: <b>server name</b>, <b>URL</b>, and <b>description</b>. Description helps AI understand what the MCP server does and helps AI select this server when required.

        <Frame>
    <img
        className="block dark:hidden"
        src="/images/light/integration/mcp/add_mcp.png"
        alt="MCP configuration"
        title="Configure MCP"
    />
    <img
        className="hidden dark:block"
        src="/images/dark/integration/mcp/add_mcp.png"
        alt="MCP configuration"
        title="Configure MCP"
    />
</Frame>
    </Step>
    <Step title="Add MCP Server">
        Click Add Server and wait for [Dume.ai](http://Dume.ai) to connect to the server. Once added, Dume ai will call the MCP server automatically whenever required.
    </Step>
    <Step title="Test MCP server">
        Once connected, you can test the MCP servers and it should show the MCP server as connected.

         <Frame>
    <img
        className="block dark:hidden"
        src="/images/light/integration/mcp/you_servers_test.png"
