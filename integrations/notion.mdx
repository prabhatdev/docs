## Troubleshooting

<AccordionGroup>
<Accordion title="Connection and Authentication Issues">
  **Common workspace connection problems:**
  
  **OAuth authentication failed:**
  - Verify you have admin permissions for the Notion workspace
  - Clear browser cookies and retry authentication in incognito mode
  - Check that Notion integration permissions haven't been revoked
  - Ensure your Notion account has active workspace access
  
  **Workspace not syncing:**
  - Confirm Notion service status and availability
  - Refresh the integration connection in Dume settings
  - Verify workspace permissions haven't changed
  - Test with simple queries to check connectivity
</Accordion>

<Accordion title="Content Access and Permission Errors">
  **Permission and access problems:**
  
  **"Insufficient permissions" errors:**
  - Reconnect Notion integration with required permissions
  - Check workspace-level permission settings in Notion
  - Verify access to specific pages and databases
  - Ensure content isn't in private or restricted sections
  
  **Missing pages or databases:**
  - Confirm selected content is included in integration scope
  - Check page and database visibility settings
  - Verify content hasn't been archived or deleted
  - Test access to individual items to isolate issues
</Accordion>

<Accordion title="Content Creation and Modification Issues">
  **Problems with workspace operations:**
  
  **Pages not being created:**
  - Verify workspace write permissions are enabled
  - Check for workspace storage limits or restrictions
  - Ensure target location exists and is accessible
  - Test with simple page creation first
  
  **Database operations failing:**
  - Confirm database structure and property permissions
  - Verify database isn't read-only or locked
  - Check for required properties that might be missing
  - Test with basic database entry creation
</Accordion>

<Accordion title="Performance and Search Issues">
  **Optimization for better performance:**
  
  **Slow search responses:**
  - Limit search scope to specific workspace sections
  - Use more specific search terms and filters
  - Check internet connection stability
  - Try searching in smaller content sets first
  
  **Content indexing delays:**
  - Allow time for new content to be indexed
  - Refresh integration if delays persist
  - Check Notion service status for performance issues
  - Use manual sync commands for immediate updates
</Accordion>
</AccordionGroup>
