## Overview
Connect Google Drive so Dume can find files, check what's in a folder, move files around, and pull a file's contents into a conversation.

<Warning>
Google Drive is one of the newer integrations and still being rolled out. If a Drive request doesn't work yet, try again shortly, or fall back to [Google Docs](/integrations/google_docs) or [Google Sheets](/integrations/google_sheets) if the file is one of those types.
</Warning>

## 1. Connect (OAuth)
<Steps>
  <Step title="Open Integrations">Go to **Integrations**.</Step>
  <Step title="Authenticate">Click **Connect Integration** on the Google Drive card and choose the right Google account.</Step>
  <Step title="Grant Access">Allow the requested Drive permissions.</Step>
  <Step title="Test">Ask: "Find my recent Google Drive files."</Step>
</Steps>

<Tip>Revoke anytime: Google Account → Security → Third-party access.</Tip>

## 2. Supported actions
- Find files or folders by name or keyword
- Download a file's contents into the conversation
- Create a folder
- Move a file to a different folder
- Delete a file

## 3. Quick commands
```
Find files about the Q4 budget
List everything in my "Marketing" folder
Move "Old Contract.pdf" to Archive
Create a folder called "2025 Contracts"
```

## 5. Troubleshooting
| Issue | Fix |
| ----- | --- |
| File not found | Use the exact filename, or search by keyword instead |
| Permission error | Reconnect and grant Drive access |
| Wrong file affected | Include the full filename and folder to disambiguate |

## 6. Security
- OAuth tokens only, no passwords stored
- Scoped to the Drive access you grant
- Revocable anytime
- Move and delete actions can request confirmation
