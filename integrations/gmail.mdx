## Overview
Connect Gmail to read, summarize, compose, send, organize, and label emails with simple chat commands.

## 1. Connect Gmail (OAuth)
<Steps>
  <Step title="Open Integrations">Go to Settings → Integrations → Gmail.</Step>
  <Step title="Start OAuth">Click Connect Gmail.</Step>
  <Step title="Select Account">Choose the correct Google account.</Step>
  <Step title="Grant Scopes">Review and allow requested permissions (read, send, manage labels).</Step>
  <Step title="Confirm">Return to Dume. Status shows Connected. Ask: "Show my recent emails."</Step>
</Steps>

<Tip>Passwords are never stored. You can revoke access anytime in Google Account → Security → Third-party access.</Tip>

## 2. Automate Inbox Tasks with Routines

Connecting Gmail doesn't turn on any background automation by itself. To get a recurring inbox summary or a morning briefing, set up a [routine](/routines/overview): the **Morning Briefing** template pulls from your inbox, calendar, and the news on a daily schedule, and you can write your own instruction for anything more specific, like triaging unread mail every hour.

## 3. Set Display Name for Connected Account
Give your connected Gmail account a **display name** to make it easy to pick the right one in chat (useful when you have multiple Gmail accounts).

<Steps>
  <Step title="Open Settings Tab">Settings → Integrations → Gmail → **Settings** tab.</Step>
  <Step title="Edit Display Name">Click the pencil icon next to **Display Name**, type a friendly name (e.g., “Sales Inbox” or “Support@Acme”), and save.</Step>
  <Step title="Verify">Ensure the **Connected Account** email matches the inbox you intend to use.</Step>
</Steps>

## 4. Supported Gmail Actions
| Capability | Internal Operation |
| ---------- | ------------------ |
| List emails | GMAIL_LIST_EMAILS |
| Describe / summarize an email | GMAIL_DESCRIBE_EMAIL |
| Compose draft | GMAIL_COMPOSE_EMAIL |
| Reply to an email | GMAIL_REPLY_TO_EMAIL |
| Send email (new or draft) | GMAIL_SEND_EMAIL / GMAIL_SEND_DRAFT_EMAIL |
| Delete an email | GMAIL_DELETE_EMAIL |
| List drafts | GMAIL_LIST_DRAFTS |
| Mark read / unread | GMAIL_MARK_READ_EMAIL_UNREAD |
| Move email (apply label / folder) | GMAIL_MOVE_EMAIL |
| List labels | GMAIL_LIST_EMAIL_LABELS |
| Create label | GMAIL_CREATE_EMAIL_LABEL |

## 7. Troubleshooting (Fast)
| Issue | Fix |
| ----- | --- |
| OAuth failed | Retry in incognito; ensure correct Google account. |
| No emails returned | Check account; try: "Show recent emails" to test. |
| Permission error | Reconnect and accept all requested scopes. |
| Action not applied | Confirm message ID exists; retry with more specific query. |
| Routine not running | Check its status on the [Routines](/routines/overview) page. |

## 8. Security Notes
- OAuth tokens only; no password storage.
- Scoped access: read, send, labels.
- Revoke anytime in Google security settings.
