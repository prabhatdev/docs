## Troubleshooting

<AccordionGroup>
<Accordion title="Connection and Authentication Issues">
  **Common Google Sheets connection problems:**
  
  **OAuth authentication failed:**
  - Clear browser cookies and retry authentication in incognito mode
  - Verify you're logged into the correct Google account with spreadsheet access
  - Check Google account security settings for third-party app permissions
  - Ensure Google Sheets API access is enabled in your account
  
  **Spreadsheets not syncing:**
  - Check Google Drive and Sheets service status
  - Refresh the integration connection in Dume settings
  - Verify spreadsheet permissions haven't been revoked or changed
  - Test with simple spreadsheet queries to check connectivity
</Accordion>

<Accordion title="Data Access and Permission Errors">
  **Permission and access problems:**
  
  **"Insufficient permissions" errors:**
  - Reconnect Google Sheets integration with all required permissions
  - Check individual spreadsheet sharing and permission settings
  - Verify access to specific folders and shared spreadsheets
  - Ensure spreadsheets aren't in private or restricted areas of your Drive
  
  **Missing spreadsheets in operations:**
  - Confirm spreadsheet scope includes the target files or folders
  - Check spreadsheet visibility settings in Google Drive
  - Verify spreadsheets aren't archived, deleted, or moved to different locations
  - Test access to individual spreadsheets to isolate permission issues
</Accordion>

<Accordion title="Data Operations and Calculation Issues">
  **Problems with spreadsheet operations:**
  
  **Calculations not working correctly:**
  - Verify data format consistency across columns and ranges
  - Check for hidden or filtered data that might affect calculations
  - Ensure date and number formats are properly recognized
  - Test with simpler data sets to isolate calculation problems
  
  **Data import and export failures:**
  - Check source data format compatibility and structure
  - Verify target spreadsheet has sufficient space and proper permissions
  - Ensure data sources are accessible and properly authenticated
  - Test with smaller data sets before processing large imports
</Accordion>

<Accordion title="Performance and Processing Issues">
  **Optimization for better performance:**
  
  **Slow spreadsheet operations:**
  - Limit operations to specific data ranges rather than entire spreadsheets
  - Break large data processing into smaller, manageable chunks
  - Check internet connection stability for Google Sheets API calls
  - Optimize spreadsheet structure by removing unnecessary formatting or formulas
  
  **Data processing delays:**
  - Allow additional time for complex calculations and large dataset operations
  - Use more specific queries to reduce processing scope and complexity
  - Check Google Sheets API quota limits if experiencing frequent delays
  - Consider splitting large spreadsheets into multiple smaller files for better performance
</Accordion>
</AccordionGroup>
