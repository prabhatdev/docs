## Overview
Connect Microsoft 365 to access files, calendar, chats, tasks, notes, Excel data, contacts, teams, and SharePoint content through natural language. (Email actions are documented separately.)

## 1. Connect Microsoft 365 (OAuth)
<Steps>
  <Step title="Open Integrations">Settings → Integrations → Microsoft 365.</Step>
  <Step title="Start OAuth">Click Connect Microsoft.</Step>
  <Step title="Select Account">Choose work or school account.</Step>
  <Step title="Grant Scopes">Allow requested permissions (files, calendar, Teams, tasks, etc.).</Step>
  <Step title="Confirm">Status shows Connected. Test: “List my upcoming meetings.”</Step>
</Steps>

<Tip>You can revoke access anytime in Azure/My Account → Privacy & security → Apps with access.</Tip>

## 5. Troubleshooting (Fast)
| Issue | Fix |
| ----- | --- |
| OAuth fails | Retry; ensure correct account and pop-ups allowed. |
| Empty results | Confirm resource exists; try a simpler list command. |
| Permission denied | Reconnect and accept scopes; admin may need to approve. |
| File not found | Provide full path or ID; list folder files first. |
| Excel range error | Verify worksheet name and cell range syntax. |

## 6. Security Notes
- Token-based OAuth; no password storage.
- Granular Microsoft Graph scopes.
- You can revoke in account security any time.
- Actions requiring modification (create/update/delete) may prompt for confirmation.
