## Troubleshooting

<AccordionGroup>
<Accordion title="Connection and Authentication Issues">
  **Common GitHub connection problems:**
  
  **OAuth authentication failed:**
  - Clear browser cookies and retry authentication in incognito mode
  - Verify you're logged into the correct GitHub account with repository access
  - Check GitHub account security settings and two-factor authentication
  - Ensure GitHub integration permissions haven't been revoked
  
  **Repository access errors:**
  - Confirm you have appropriate permissions for the target repositories
  - Check if repositories are private and require organization membership
  - Verify GitHub organization settings allow third-party app access
  - Test with public repositories first to isolate permission issues
</Accordion>

<Accordion title="Repository and Permission Issues">
  **Access and permission problems:**
  
  **"Insufficient permissions" errors:**
  - Reconnect GitHub integration with all required repository permissions
  - Check individual repository access settings and collaboration permissions
  - Verify organization-level permissions for private repositories
  - Ensure you have write access for repositories requiring comment creation
  
  **Missing repositories or data:**
  - Confirm repository scope includes the target repositories and organizations
  - Check if repositories have been archived, transferred, or deleted
  - Verify access to specific branches and content areas
  - Test access to individual repositories to isolate configuration issues
</Accordion>

<Accordion title="Code Review and Analysis Issues">
  **Problems with repository operations:**
  
  **Pull request analysis failures:**
  - Verify PR is accessible and not from a restricted fork
  - Check if PR contains binary files or very large changesets
  - Ensure sufficient permissions for reading PR content and files
  - Test with simpler PRs to isolate complexity-related issues
  
  **Issue management problems:**
  - Confirm issue exists and is accessible with current permissions
  - Check if issue is in a private repository requiring special access
  - Verify ability to read issue comments and metadata
  - Test with public issues first to isolate permission problems
</Accordion>

<Accordion title="Performance and API Limitations">
  **Optimization for better performance:**
  
  **Slow repository operations:**
  - Limit analysis scope to specific files or directories when possible
  - Check GitHub API rate limits and usage quotas
  - Use more targeted queries for large repositories
  - Consider breaking large operations into smaller, focused requests
  
  **API quota and rate limiting:**
  - Monitor GitHub API usage through integration settings
  - Spread operations across time to avoid rate limit hits
  - Use more efficient queries that return only necessary data
  - Consider GitHub Enterprise for higher API limits if needed
</Accordion>
</AccordionGroup>
