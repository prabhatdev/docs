## Troubleshooting

<AccordionGroup>
<Accordion title="Connection and Authentication Issues">
  **Common calendar connection problems:**
  
  **OAuth authentication failed:**
  - Clear browser cookies and try authentication in incognito mode
  - Ensure you're logged into the correct Google account
  - Check Google account security settings for third-party app access
  - Verify that calendar API access is enabled in your Google account
  
  **Calendar not syncing:**
  - Check if Google Calendar service is operational
  - Refresh the integration connection in Dume settings
  - Verify calendar permissions haven't been revoked
  - Test with a simple calendar query to check connectivity
</Accordion>

<Accordion title="Calendar Access and Permission Errors">
  **Permission and access problems:**
  
  **"Insufficient permissions" errors:**
  - Reconnect Google Calendar integration with full permissions
  - Check that all required calendar scopes are authorized
  - Verify access to specific calendars in Google Calendar settings
  - Ensure calendar sharing settings allow external app access
  
  **Missing calendar or events:**
  - Confirm which calendars are selected for integration
  - Check calendar visibility settings in Google Calendar
  - Verify that events aren't in hidden or archived calendars
  - Test access to specific calendar types (personal, work, shared)
</Accordion>

  - Test with simple event creation first
  
  **Scheduling conflicts and errors:**
  - Verify attendee email addresses are correct
  - Check that invitees have calendar access permissions
  - Confirm time zone settings match expectations
  - Test rescheduling with simpler date/time combinations
  
  **Recurring event problems:**
  - Ensure recurring event patterns are clearly specified

  - Verify permissions for series-wide modifications
  - Test with simple recurring patterns first

  - Use specific calendar names in queries when possible
  - Check internet connection stability for Google Calendar API
  
  **Sync delays between Dume and Google Calendar:**
  - Allow up to 5 minutes for changes to propagate

  - Check Google Calendar web interface to verify changes
  - Use "refresh calendar" command to force immediate sync
