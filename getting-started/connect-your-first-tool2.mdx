## Why Connect?
Unlock real-time data, automate work, and give Dume richer context. Start with a high-impact tool (Calendar, Slack, GitHub).

<Tip>Each connection compounds Dume’s usefulness.</Tip>

## 5-Minute Setup
<Steps>
  <Step title="Open Integrations">Go to Settings → Integrations.</Step>
  <Step title="Pick a Tool">Choose a frequently used service. Review scopes.</Step>
  <Step title="Start OAuth">Click Connect. Redirect opens the provider login.</Step>
  <Step title="Authorize">Sign in → Review permissions → Allow.</Step>
  <Step title="Verify">Status shows Connected. Ask Dume: “What’s on my calendar today?”</Step>
</Steps>

## OAuth in 20 Seconds
- No passwords shared; token-based access.
- Scopes = exactly what Dume can read/write.
- You can revoke anytime (Settings → Integrations).

<Note>Approve only scopes you need.</Note>

## Quick Tests
What's on my calendar today? Show my latest GitHub commits. List unread Slack messages.

If denied, re-check permissions or reconnect.

## Fast Troubleshooting
| Issue | Fix |
| ----- | --- |
| OAuth failed | Retry with stable network; disable blockers. |
| Connected but empty | Confirm correct account + granted read scope. |
| Permission errors | Reconnect; verify org/app restrictions. |
| Missing integration | Submit request or use custom/webhook option. |

## Next Moves
- Add more core tools (Drive, Jira, Notion).
- Enable workflows (automation between tools).
- Tune privacy & permission scopes.
- Try multi-tool prompts: “Summarize this week’s meetings + open Jira issues.”
