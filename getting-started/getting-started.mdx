<Steps>
  <Step title="Create an account">
    Go to <a href="https://app.dume.ai" target="_blank" rel="noopener noreferrer">Dume.ai</a>, enter your email and OTP, set password and login.
  </Step>
  <Step title="Connect core tools">
    Visit <a href="https://app.dume.ai/integrations" target="_blank" rel="noopener noreferrer">Integrations</a> and connect:
    <ul>
      <li><strong>Gmail</strong> (email summarization+ triage + search + reply context)</li>
      <li><strong>Calendar</strong> (meeting scheduling & follow-ups)</li>
    </ul>
    All via OAuth. Revocable anytime. Multi-account supported.
    <Image src="/images/integrations.png" alt="Integrations" />
  </Step>
  <Step title="Clone and run a workflow">
    Open <a href="https://app.dume.ai/workflow" target="_blank" rel="noopener noreferrer">Workflow</a> page → Switch to Public Workflows Tab→ choose <em>Email Triage</em> → <strong>Clone Workflow</strong> → <strong>Run</strong>.
    <br/><em>Connected email account's emails will be auto triaged once workflow executes.</em>
  </Step>
</Steps>

<Tabs>
  <Tab title="Quick Prompt">
    Example prompt to convert unread emails to tasks:
    <CodeGroup>
      <CodeBlock language="markdown">
        {"Summarize my last 50 unread emails. Flag any that need a reply today. Output JSON with fields: subject, sender, priority, suggested_action.\n"}
      </CodeBlock>
    </CodeGroup>
  </Tab>
  <Tab title="PRD → Jira">
    Use the PRD Generator template then:
    <CodeGroup>
      <CodeBlock language="markdown">
        {"Prompt:\nFrom the PRD in Notion titled 'Mobile Onboarding Revamp', create Jira stories with acceptance criteria, labels=onboarding,mobile, estimate story points by complexity.\n"}
      </CodeBlock>
    </CodeGroup>
  </Tab>
</Tabs>
