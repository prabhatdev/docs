## How It Will Work

<Steps>
  <Step title="Install the App">
    Add the Dume.ai app to your Slack workspace from the Slack App Directory.
  </Step>
  
  <Step title="Connect Your Account">
    Link your Dume.ai account to authenticate and sync your data.
  </Step>
  
  <Step title="Start Chatting">
    Message the Dume.ai bot in DMs or mention it in channels to start getting help.
  </Step>
  
  <Step title="Use Slash Commands">
    Access quick actions with slash commands like `/dume schedule`, `/dume task`, or `/dume email`.
  </Step>
</Steps>

## Slash Commands (Planned)

Common slash commands that will be available:

| Command | Description |
|---------|-------------|
| `/dume help` | Get help and see available commands |
| `/dume task [description]` | Create a new task quickly |
| `/dume schedule` | View your calendar for today |
| `/dume email` | Check recent important emails |
| `/dume workflow [name]` | Trigger a custom workflow |
| `/dume ask [question]` | Ask your AI assistant anything |
