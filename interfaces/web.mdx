Dume.ai's web interface provides full access to your personal executive AI assistant from any modern web browser. Whether you're on desktop, laptop, or tablet, manage your tasks, communications, and workflows seamlessly.

<Note>
The web interface is the primary way to access all of Dume.ai's features, including workflow creation, integrations management, and advanced AI interactions.
</Note>

## Getting Started

<Steps>
  <Step title="Visit the Web App">
    Navigate to [app.dume.ai](https://app.dume.ai) in your preferred web browser.
    
    <Tip>
    For the best experience, use the latest version of Chrome, Firefox, Safari, or Edge.
    </Tip>
  </Step>
  
  <Step title="Sign In or Create Account">
    Log in with your existing account or create a new one using email, Google, or Microsoft authentication.
  </Step>
  
  <Step title="Start Using Your AI Assistant">
    Begin chatting with your AI executive assistant immediately. Ask questions, delegate tasks, or set up automations.
  </Step>
</Steps>

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Do I need to install anything?">
    No! Dume.ai is a web application that runs entirely in your browser. No downloads or installations are required.
  </Accordion>
  
  <Accordion title="Can I use Dume.ai offline?">
    Dume.ai requires an internet connection to function, as it processes AI requests and syncs data in real-time.
  </Accordion>
  
  <Accordion title="Is my data accessible on mobile browsers?">
    Yes, the web interface works on mobile browsers, though for the best mobile experience, we recommend using the WhatsApp interface on mobile devices.
  </Accordion>
  
  <Accordion title="How do I report a bug or issue?">
    Contact our support team directly through the help button in the web interface or email care@dume.ai.
  </Accordion>
  
  <Accordion title="Can I use multiple accounts?">
    You can sign out and sign in with different accounts, but only one account can be active per browser session. Use different browsers or incognito mode for multiple simultaneous sessions.
  </Accordion>
</AccordionGroup>
