<Note>Part of [Dume Office](/office/overview), currently in **beta**.</Note>

Dume PDF opens, reads, and edits real `.pdf` files on your machine in Cowork desktop, with Dume's AI copilot built into the editor itself.

## Opening a PDF

- **Ask in chat**: attach or reference a PDF and ask Dume to work on it; it opens in Dume PDF.
- **New File** inside Dume Office if you're building a PDF from other content.
- **Open an existing `.pdf`** from Cowork; it launches in Dume PDF already editable.

See [Dume Office](/office/overview) for all three entry points in detail.

## What the copilot can do

Because the copilot has the PDF open, it can do anything you'd otherwise do by hand: summarize a long document, answer questions about what's in it, fill out a form, or edit the text directly instead of you exporting it elsewhere first. Point it at a specific page or section rather than the whole file for a tighter result.

```
Summarize this PDF in five bullet points
What does section 3 say about liability?
Fill in this form with the details from my profile
Edit page 2 to fix the typo in the second paragraph
Pull the line items from this invoice into a table
```

## A note on scanned documents

Editing and Q&A work best on PDFs that already contain real text (exported from a document, not a photo or scan). A scanned PDF may need OCR to work reliably; if Dume can't read text from a page, that's usually why.
