<Note>Part of [Dume Office](/office/overview), currently in **beta**.</Note>

Dume Docs is a native `.docx` word processor in Cowork desktop. It opens and saves real Word files on your machine, and Dume's AI copilot is built into the editor itself.

## Opening a doc

- **Ask in chat**: "Draft a one-pager on our pricing change" opens Dume Docs with a first draft.
- **New File** inside Dume Office for a blank document.
- **Open an existing `.docx`** from Cowork; it launches in Dume Docs already editable.

See [Dume Office](/office/overview) for all three entry points in detail.

## What the copilot can do

Because the copilot has the document open, it can do anything you'd otherwise do by hand: write a first draft from a prompt, rewrite or tighten a selection, restructure sections, fix formatting, proofread, or summarize a long document back to you before you read the whole thing. Point it at a specific paragraph or heading rather than "make it better" for a tighter result.

```
Draft a one-pager on our new pricing tiers
Rewrite the second paragraph to be more direct
Add an executive summary at the top
Reformat this into three sections: Overview, Risks, Next steps
Summarize this document in five bullet points
```

## Google Docs vs. Dume Docs

Dume Docs edits a local `.docx` file. If you instead want Dume to edit a document that lives in Google Drive without ever downloading it, use the [Google Docs integration](/integrations/google_docs). To move a Google Doc into Dume Docs, download it, edit it locally, then push it back to Drive when you're done; see [Working with Google Drive files](/office/overview#working-with-google-drive-files).
