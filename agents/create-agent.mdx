## 1. Introduction to Agent Studio

Agent Studio is the environment where you design, build, and manage dedicated AI assistants. Each agent is tailored to a focused domain (support, research, reporting, etc.) and responds within the guardrails you define.

<List>
	<li><strong>Purpose-driven:</strong> Every agent has a clearly scoped mission.</li>
	<li><strong>Configurable personality:</strong> Control tone, style, and escalation rules.</li>
	<li><strong>Tool-enabled:</strong> Agents can invoke workflows, integrations, and app tools.</li>
</List>

---

## 2. Core Concepts

<Tabs>
	<Tab title="Agent" icon="user">
		<p>The persona you create. It is the front-end chat interface that interprets user intent and triggers configured capabilities.</p>
		<p>Think of it as a specialized analyst, support rep, or automation driver that you can deploy anywhere Dume.ai supports agents.</p>
	</Tab>
	<Tab title="Workflow" icon="cpu">
		<p>A reusable, multi-step automation built in Workflow Studio. Workflows are where you orchestrate tasks such as scraping data, calling APIs, branching logic, and shaping responses.</p>
		<p>Agents gain superpowers when you connect them to the right workflows.</p>
	</Tab>
	<Tab title="Tools" icon="tool">
		<p>Atomic capabilities you grant to an agent. Tools fall into three categories:</p>
		<ul>
			<li><strong>Integrations:</strong> Secure connections to SaaS systems like Google Sheets, Jira, or Slack.</li>
			<li><strong>App Tools:</strong> Built-in Dume.ai utilities (e.g., Web Scraper, Create Pie Chart, Send Email Notification).</li>
			<li><strong>Workflows:</strong> Custom automations you have created or cloned for complex jobs.</li>
		</ul>
	</Tab>
</Tabs>

## 3. Prepare the Agent's Capabilities

Before configuring the agent, ensure the workflow it needs is available and published. Our Competitor Finder agent depends on the "Competitor Finder" workflow.

<Steps>
	<Step title="Clone a Public Workflow">
		<ul>
			<li>Open the <strong>Workflow</strong> tab from the left sidebar to access Workflow Studio.</li>
			<li>In <strong>Discover Public Workflows</strong>, locate <em>Competitor Finder</em>.</li>
			<li>Select <strong>Clone Workflow</strong> to copy it into your account.</li>
			<li>The workflow opens in the visual node editor for inspection.</li>
		</ul>
	</Step>
	<Step title="Publish the Workflow">
		<ul>
			<li>Review the node logic; no edits are required for this tutorial.</li>
			<li>Click <strong>Publish</strong> in the top-right corner.</li>
			<li>Publishing makes the workflow live for your workspace while remaining private to your account.</li>
		</ul>
	</Step>
</Steps>

## 4. Create a New Agent

There are two workflows for agent creation: AI-assisted scaffolding or manual configuration.

<Tabs>
	<Tab title="Method A · AI-Assisted" icon="sparkles">
		
		<ol>
			<li>Navigate to the <strong>Agent</strong> tab to open the Agent Studio dashboard.</li>
			<li>Click <strong>Create using AI</strong>.</li>
			<li>Describe the desired agent in the <em>Agent Requirements</em> field.</li>
		</ol>
		<CodeGroup>
			```text
			An agent that functions as a competitor finder for my business.
			```
		</CodeGroup>
		<ol start="4">
			<li>Select <strong>Generate Agent</strong>. Agent Studio pre-fills the configuration.</li>
			<li>Continue to Section 5 to review and refine each field.</li>
		</ol>
	</Tab>
	<Tab title="Method B · Manual" icon="edit">
		<Image
			src="/images/agents/create/manual.png"
			alt="Blank Create Agent modal"
			caption="Manual creation gives you full control over every parameter from the start."
			border="true"
		/>
		<ol>
			<li>From Agent Studio, choose the <strong>+ Create New Agent</strong> card.</li>
			<li>A blank configuration modal appears.</li>
			<li>Populate each field manually using the guidance in Section 5.</li>
		</ol>
	</Tab>
</Tabs>

### 5.1 Define the Agent's Identity

<List>
	<li><strong>Agent Name:</strong> Use a clear, descriptive title.<br />Example: <em>Competitor Finder</em>.</li>
	<li><strong>What does your agent do?</strong> Provide explicit instructions that set scope, success criteria, and limitations.<br />Example: <em>This agent identifies and analyzes competitors based on a company name and URL. It leverages the Competitor Finder workflow to scrape website features and produce a detailed comparison.</em></li>
	<li><strong>Main Skill:</strong> Assign the role that best matches its purpose.<br />Example: <em>Market Research Analyst</em>.</li>
	<li><strong>Behavior Guidelines:</strong> Define tone and guardrails.<br />Example: <em>Be professional, data-driven, and analytical. Present findings in a structured format and ask clarifying questions when requests are ambiguous.</em></li>
</List>

### 5.2 Assign Tools and Capabilities

Scroll to <strong>Add tools for your agent to use</strong>. You will see tabs for the three capability types.

<Tabs>
	<Tab title="Integrations">
		<Image
			src="/images/agents/create/integrations-tab.png"
			alt="Integrations tab in agent configuration"
			caption="Attach SaaS integrations like Google Sheets or Jira if the agent needs external data."
			border="true"
		/>
		<p>Add any activated third-party apps the agent must leverage. Skip integrations that are not essential to keep the scope tight.</p>
	</Tab>
	<Tab title="App Tools">
		<Image
			src="/images/agents/create/app-tools-tab.png"
			alt="App tool selection for agents"
			caption="Select (or remove) single-task Dume.ai tools the agent should call."
			border="true"
		/>
		<p>Choose built-in utilities carefully. For this tutorial, AI may suggest <code>webSearchBasic</code>. Remove redundant tools when a workflow already performs the same action to avoid conflicting behavior.</p>
		<Callout type="warning">If the Competitor Finder workflow already handles web scraping, remove the basic web search tool to keep executions consistent.</Callout>
	</Tab>
	<Tab title="Workflows">
		<Image
			src="/images/agents/create/workflow-tab.png"
			alt="Workflow tab within agent configuration"
			caption="Grant the agent permission to execute the Competitor Finder workflow."
			border="true"
		/>
		<ol>
			<li>Open the <strong>Workflows</strong> tab.</li>
			<li>Select the published <strong>Competitor Finder</strong> workflow.</li>
			<li>This links the agent to the entire automation so it can scrape, compare, and summarize competitors.</li>
		</ol>
	</Tab>
</Tabs>

## 7. Conclusion

By cloning and publishing the Competitor Finder workflow, configuring a dedicated agent, and linking the workflow as a tool, you now have a specialized market research assistant ready to deploy. Apply this framework to craft agents for customer support, analytics, reporting, and any other domain where structured automation paired with conversational AI delivers value.

<Callout type="success">
The methodology scales: prepare the right workflow, grant deliberate capabilities, and shape the agent's behavior. Repeat to build a portfolio of focused assistants tailored to your organization.
