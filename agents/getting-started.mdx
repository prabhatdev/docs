## 🏗️ Create Your Agent

<Steps>
  <Step title="Start a New Project">
    <Image
      src="/images/agents/create-hero.png"
      alt="Create new agent modal placeholder"
      caption="Drop in a screenshot of the Create Agent modal."
      border="true"
    />
    <ul>
      <li>Open <strong>Agent Studio → Create New Agent</strong>.</li>
      <li>Describe the agent name, goals, target persona, and sample prompts.</li>
      <li>Use <strong>Create using AI ✨</strong> to auto-fill starter content.</li>
    </ul>
  </Step>
  <Step title="Add Capabilities">
    <Image
      src="/images/agents/capabilities.png"
      alt="Agent capabilities configuration placeholder"
      caption="Showcase the panel where you attach skills, MCP integrations, and workflows."
      border="true"
    />
    <ul>
      <li>Attach core <strong>Skills</strong> such as Web Search or Data Fetch.</li>
      <li>Connect <strong>MCP integrations</strong> (email, CRM, calendar, internal APIs).</li>
      <li>Layer <strong>workflows</strong> or automation blocks for multi-step tasks.</li>
    </ul>
  </Step>
  <Step title="Test & Deploy">
    <Image
      src="/images/agents/test-and-deploy.png"
      alt="Agent testing console placeholder"
      caption="Swap in a screenshot of the testing console or deployment settings."
      border="true"
    />
    <ul>
      <li>Preview conversations and iterate on prompts.</li>
      <li>Publish to your workspace when ready.</li>
      <li>Share with teammates or embed in workflows.</li>
    </ul>
  </Step>
</Steps>

## 🛠️ Agent Structure

<Accordion title="Profile">
  <p>Identity, tone, and behavioral rules that define your agent's voice.</p>
</Accordion>
<Accordion title="Tools">
  <p>Actions the agent can execute — APIs, workflows, automations, and custom MCP skills.</p>
</Accordion>
<Accordion title="Memory">
  <p>Long-term context, preferences, and conversation history for personalization.</p>
</Accordion>
<Accordion title="Safety">
  <p>Guardrails, permissions, and escalation settings that keep responses on-policy.</p>
</Accordion>
<Accordion title="Integrations">
  <p>Connections to CRMs, calendars, knowledge bases, and internal services.</p>
</Accordion>

## ❓ FAQ

<Accordion title="Do agents run autonomously?">
  <p>Yes. Combine triggers, guardrails, and workflows to allow safe autonomous execution.</p>
</Accordion>
<Accordion title="Can I integrate internal APIs?">
  <p>Absolutely — register secure MCP tools or custom connectors to expose internal services.</p>
</Accordion>
<Accordion title="Is coding required?">
  <p>No. Everything works through the UI, though developers can extend agents with code when needed.</p>
</Accordion>
