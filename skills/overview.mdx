A skill is a defined capability Dume can use during a conversation: sending an email, researching the web, generating an OAuth connect link. Dume ships with a set of pre-packaged skills (see [Bundled skills](/skills/bundled-skills)), and you can add your own (see [Building a custom skill](/skills/custom-skills)).

{/* TODO: Phase 3 screenshot — Skill Library, Cowork desktop app */}

The Skill Library, where you manage which skills are active, is available in the Cowork desktop app. See [Web app vs. Cowork desktop](/product/web-vs-cowork) for what else differs between the two.
