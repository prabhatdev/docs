Every session, on web or desktop, has access to a shared core set of skills. Cowork desktop adds a few more that only make sense running locally.

## Shared across web and desktop

| Skill | What it does |
| --- | --- |
| Call user | Places an outbound phone call to your linked number with a conversational agenda |
| Connect integration | Generates OAuth connect links for your integrations |
| Daily morning briefing | Builds a morning brief from your inbox, calendar, and news |
| Email sending | Sends email, with attachments, from your Dume address |
| Google Workspace | Searches, downloads, and uploads files across Drive, Docs, and Sheets |
| Media download | Downloads a media attachment you sent Dume |
| Personalize (user context) | Keeps Dume's understanding of your profile, tools, and routines up to date; runs automatically at the start of every session |
| Routines | Creates and manages your scheduled routines |
| Speech to text | Transcribes an audio file |
| Web research | Researches a topic across multiple sources and summarizes it |
| WhatsApp messaging | Sends messages, files, and media to your linked WhatsApp |

## Cowork desktop only

| Skill | What it does |
| --- | --- |
| Agent browser | Automates a real browser session: navigate, click, fill forms, scrape, screenshot; see [Control the browser](/do-work-with-it/control-the-browser) |
| Skill creator | A meta-skill that helps you author a new custom skill |
| Suggest schedule | Proactively offers to turn a one-off task into a recurring routine |

These need either a local browser to drive or a local scheduler to hook into, so they're only available in [Dume Cowork](/product/dume-cowork), not the web app.
