Beyond the bundled set, you can add a skill of your own from the Skill Library, three ways:

- **Create with AI** — describe what you want the skill to do, and Dume drafts it for you.
- **Import from file** — upload a local `SKILL.md` file.
- **Import from GitHub** — paste a link to a `SKILL.md` file in a public repo.

{/* TODO: Phase 3 screenshot — Add Skill dropdown with the three options */}

Custom skills appear separately from the pre-packaged ones, under **My Skills**, and you can edit, disable, or delete them at any time.
