## Overview

Artifacts in Dume.ai are structured content objects that allow you to create, edit, and manage different types of content including text documents, spreadsheets, code files, and images. The artifact system provides three core functions to work with these content types.

<Info>
Artifacts persist across conversations and can be saved externally for later use or sharing.
</Info>

## Artifact Types

<Tabs>
  <Tab title="Text" icon="file-text">
    Create and edit rich text documents, markdown files, or plain text content.
    
    **Use cases:**
    - Documentation and reports
    - Blog posts and articles  
    - Meeting notes and summaries
    - Creative writing
  </Tab>
  
  <Tab title="Sheet" icon="table">
    Generate and manipulate spreadsheet data with calculations and formatting.
    
    **Use cases:**
    - Data analysis and calculations
    - Budget planning and tracking
    - Inventory management
    - Project timelines
  </Tab>
  
  <Tab title="Code" icon="code">
    Write, edit, and manage code files with syntax highlighting.
    
    **Use cases:**
    - Script development
    - Configuration files
    - API implementations  
    - Code snippets and examples
  </Tab>
  
  <Tab title="Image" icon="image">
    Generate, edit, and manage visual content and diagrams.
    
    **Use cases:**
    - Illustrations and graphics
    - Charts and diagrams
    - UI mockups
    - Visual documentation
  </Tab>
</Tabs>

## Available Functions

### Create Artifact

Creates a new artifact of the specified type with initial content.

<CodeGroup>

```bash Create Text Artifact
create_artifact(
  type="text",
  title="Meeting Notes",
  content="# Team Meeting - Q1 Planning\n\n## Agenda\n- Budget review\n- Project timeline"
)
```

```bash Create Code Artifact
create_artifact(
  type="code",
  title="API Helper Functions",
  language="python",
  content="def fetch_user_data(user_id):\n    return api.get(f'/users/{user_id}')"
)
```

```bash Create Sheet Artifact
create_artifact(
  type="sheet",
  title="Budget Tracker",
  data=[
    ["Category", "Planned", "Actual"],
    ["Marketing", 5000, 4800],
    ["Development", 12000, 11500]
  ]
)
```

```bash Create Image Artifact
create_artifact(
  type="image",
  title="Process Diagram",
  prompt="Create a flowchart showing user registration process"
)
```

</CodeGroup>

<Note>
When creating code artifacts, always specify the programming language for proper syntax highlighting.
</Note>

### Update Artifact

Modifies existing artifact content while preserving the artifact structure.

<Accordion title="Update Examples">

<CodeGroup>

```bash Update Text Content
update_artifact(
  artifact_id="text_123",
  content="# Updated Meeting Notes\n\n## Key Decisions\n- Approved budget increase\n- Extended timeline by 2 weeks"
)
```

```bash Update Code Content
update_artifact(
  artifact_id="code_456",
  content="def fetch_user_data(user_id, include_profile=True):\n    endpoint = f'/users/{user_id}'\n    if include_profile:\n        endpoint += '?include=profile'\n    return api.get(endpoint)"
)
```

```bash Update Sheet Data
update_artifact(
  artifact_id="sheet_789",
  data=[
    ["Category", "Planned", "Actual", "Variance"],
    ["Marketing", 5000, 4800, -200],
    ["Development", 12000, 11500, -500],
    ["Total", 17000, 16300, -700]
  ]
)
```

</CodeGroup>

</Accordion>

### Save Artifact External

Exports artifacts to external formats or locations for sharing and backup.

<Tabs>
  <Tab title="File Export">
    ```bash
    save_artifact_external(
      artifact_id="text_123",
      format="markdown",
      filename="meeting_notes.md"
    )
    ```
  </Tab>
  
  <Tab title="Cloud Storage">
    ```bash
    save_artifact_external(
      artifact_id="sheet_789",
      destination="google_sheets",
      share_permissions="view"
    )
    ```
  </Tab>
  
  <Tab title="Version Control">
    ```bash
    save_artifact_external(
      artifact_id="code_456",
      destination="github",
      repository="my-project",
      branch="feature/api-helpers"
    )
    ```
  </Tab>
</Tabs>

## Example Commands

<RequestExample>

```bash Create a Python Script
create_artifact(
  type="code",
  title="Data Processor",
  language="python",
  content="""
import pandas as pd
import numpy as np

def process_data(file_path):
    # Load and clean data
    df = pd.read_csv(file_path)
    df = df.dropna()
    
    # Perform calculations
    df['total'] = df['quantity'] * df['price']
    
    return df.groupby('category').sum()
"""
)
```

</RequestExample>

<ResponseExample>

```json Success Response
}
```

</ResponseExample>

</Warning>

## Best Practices

<Callout icon="lightbulb">
**Pro Tips for Artifacts**

- Use descriptive titles for easy identification
- Include comments in code artifacts for better readability
- Regularly save important artifacts externally as backups
- Use appropriate file formats when exporting (e.g., .xlsx for sheets, .py for Python code)
</Callout>

### Organizing Artifacts

- **Text artifacts**: Structure with headers and clear sections
- **Code artifacts**: Include proper documentation and error handling
- **Sheet artifacts**: Use meaningful column headers and consistent data types
- **Image artifacts**: Provide detailed prompts for better generation results

### Performance Considerations

- Keep individual artifacts under 5MB for optimal performance
- Use incremental updates rather than recreating large artifacts
- Save frequently accessed artifacts externally for faster loading
