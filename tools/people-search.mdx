## Overview

The People Search tool allows you to find detailed information about individuals using AI-powered search capabilities. Simply activate the tool with `@people_search` and describe who you're looking for.

<Info>
This tool searches public information and professional databases to provide comprehensive profiles and contact details.
</Info>

## How It Works

<Steps>
<Step title="Activate the Tool">
Type `@people_search` in the chat interface to activate the people search functionality.
</Step>

<Step title="Describe Your Search">
Provide any information you have about the person you're looking for using natural language.

<CodeGroup>
```bash Name Search
@people_search Find John Smith who works at Google in San Francisco
```

```bash Email Search
@people_search Look up the person with email john.doe@techstartup.com
```

```bash Company Search
@people_search Find the CEO of Tesla Motors
```

```bash Professional Search
@people_search Search for Sarah Johnson, marketing director at Adobe
```
</CodeGroup>
</Step>

<Step title="Review Results">
Dume.ai will provide comprehensive information including professional background, contact details, and social profiles.
</Step>
</Steps>

## Best Practices

<Tip>
**Effective Search Tips**
- Provide multiple identifying details when possible
- Use current company information for better accuracy
- Include location for common names
- Specify industry or role for broader searches
- Mention mutual connections when relevant
</Tip>
