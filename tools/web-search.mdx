## Overview

Dume.ai offers two types of web search capabilities: **Basic Web Search** for quick information gathering in chat, and **Advanced Web Search** for comprehensive research with detailed filtering and control in workflows.

<Info>
The Basic Web Search provides quick results for immediate research needs, while the Advanced Web Search offers extensive customization and deeper analysis capabilities.
</Info>

## Search Types

<Tabs>
  <Tab title="Basic Web Search" icon="search">
    **Available in:** Chat interface only
    
    **Activation:** `@web_search`
    
    **Features:**
    - Quick web results for specific objectives
    - Configurable result count and character limits
    - Simple query-based search
    - Immediate results in chat
    
    **Best for:** Quick research, fact-checking, immediate information needs
  </Tab>
  
  <Tab title="Advanced Web Search" icon="filter">
    **Available in:** Workflows only
    
    **Features:**
    - Domain inclusion/exclusion filtering
    - Content type specification (news, research, company info)
    - Full text result retrieval
    - HTML tag control and character limits
    - Highlight extraction with custom queries
    - Category-based searches
    - Live crawl settings for data freshness
    
    **Best for:** Comprehensive research, data analysis, automated workflows
  </Tab>
</Tabs>

## How It Works

### Basic Web Search (Chat Interface)

<Steps>
<Step title="Activate the Tool">
Type `@web_search` in the chat interface to activate the basic web search functionality.
</Step>

<Step title="Specify Your Objective">
Provide a clear objective and optional search queries to get relevant results.

<CodeGroup>
```bash Quick Research
@web_search Find the latest news about artificial intelligence developments
```

```bash Fact Checking
@web_search What is the current stock price of Tesla?
```

```bash Information Gathering
@web_search Research the benefits of remote work for companies
```
</CodeGroup>

<Note>
You can specify the maximum number of results and character limits to tailor the output to your needs.
</Note>
</Step>

<Step title="Review Results">
Get immediate, relevant web results formatted for easy reading in the chat interface.
</Step>
</Steps>

### Advanced Web Search (Workflows)

The Advanced Web Search provides comprehensive control over search parameters:

- **Query customization** with multiple search terms
- **Domain filtering** to include or exclude specific websites
- **Content type targeting** (news articles, research papers, company information)
- **Result formatting** with full text extraction and HTML control
- **Highlight extraction** for focused insights
- **Category-based filtering** for cleaner, more relevant data
- **Live crawl settings** to control data freshness

### Effective Search Techniques

<AccordionGroup>

<Accordion title="Basic Search Tips" icon="search">
- **Be specific** with your research objective
- **Use clear language** to describe what you're looking for
- **Specify timeframes** when looking for recent information
- **Ask focused questions** rather than broad topics

```bash Good Examples:
@web_search Latest iPhone 15 review comparisons from tech blogs
@web_search Tesla Q3 2025 earnings results and analysis
@web_search Best practices for remote team management 2025
```
</Accordion>

<Accordion title="Advanced Search Optimization" icon="filter">
- **Use domain filtering** to focus on authoritative sources
- **Specify content types** to get relevant result formats
- **Set appropriate character limits** based on your analysis needs
- **Enable highlights** to extract key insights automatically
- **Configure freshness settings** based on how current you need the data

**Domain Examples:**
- Research: `site:arxiv.org OR site:scholar.google.com`
- News: `site:reuters.com OR site:bbc.com OR site:ap.org`
- Tech: `site:techcrunch.com OR site:ars-technica.com`
- Business: `site:bloomberg.com OR site:wsj.com`
</Accordion>

</AccordionGroup>

## Search Quality & Reliability

<Warning>
Always verify important information from multiple sources, especially for business-critical decisions. Web search results reflect publicly available information and may not always be current or accurate.
</Warning>

### Source Evaluation:
- ✅ Cross-reference important facts across multiple sources
- ✅ Prefer authoritative domains for critical information
- ✅ Check publication dates for time-sensitive data
- ✅ Use domain filtering to focus on reputable sources
- ✅ Consider the context and potential bias of sources

Use web search as a powerful research tool while applying critical thinking and source validation for important decisions.
