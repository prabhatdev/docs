## How It Works

<Steps>
  <Step title="Connect Accounts">
    Add your main account, then link more via **Add Another Account**.
  </Step>
  <Step title="Label & Configure">
    Name each account (e.g., “Work Gmail”) and set defaults, notifications, or privacy.
  </Step>
  <Step title="Use Seamlessly">
    Query by account or search across all at once — Dume remembers your context.
  </Step>
</Steps>

## Example Commands

"Show emails from my work account"
"Send from my personal Gmail"
"Search all Gmail accounts for 'invoice'"


## Security & Privacy

Each account has:
- Isolated authentication tokens  
- Independent permissions and data handling  
- Secure OAuth-based access  
- Clear context switching indicators

## Get Started

1. Connect your first Gmail account  
2. Add others via **Integrations → Gmail → Add Account**  
3. Use account names in chat to direct queries  
4. Automate tasks across accounts  

<Note>
Currently available for Gmail. Other integrations launching soon.
