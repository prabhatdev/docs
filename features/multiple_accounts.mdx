## Manage Multiple Accounts Seamlessly

Multiple accounts support allows you to connect several accounts from the same service provider to Dume, giving you unified access across all your professional and personal accounts. Whether you have separate work and personal Gmail accounts, or manage multiple business accounts, Dume makes it easy to access and manage them all from one interface.

## Managing Multiple Accounts

### Account Organization and Identification

<AccordionGroup>
<Accordion title="Account Naming and Labels">
  **Organize your accounts with clear, descriptive names:**
  
  **Best naming practices:**
  ```
  ✅ "Work Gmail (company.com)"
  ✅ "Personal Gmail"
  ✅ "Freelance Projects Gmail"
  ✅ "Client XYZ Gmail"
  ```
  
  **Avoid confusing names:**
  ```
  ❌ "Gmail 1", "Gmail 2"
  ❌ "Account A", "Account B"
  ❌ "Main", "Secondary"
  ```
  
  **Custom labels and colors:**
  - Assign color codes to different account types
  - Use icons or emojis for quick visual identification
  - Group accounts by purpose (work, personal, clients)
</Accordion>

<Accordion title="Account Switching and Selection">
  **Seamless switching between accounts:**
  
  **Automatic account detection:**
  ```
  User: "Check emails from my work account"
  Dume: [Automatically uses work Gmail account]
  
  User: "Send an email from my personal account"
  Dume: [Switches to personal Gmail for composition]
  ```
  
  **Explicit account specification:**
  ```
  User: "Show me emails from john@company.com in my work account"
  User: "Draft an email from my freelance account to the client"
  User: "Search all accounts for emails about the budget meeting"
  ```
  
  **Account context memory:**
  - Dume remembers your account context within conversations
  - Continues using the same account until explicitly changed
  - Smart suggestions based on account context
</Accordion>

<Accordion title="Unified vs Separate Views">
  **Choose how to view and interact with your accounts:**
  
  **Unified view benefits:**
  - See data from all accounts in one consolidated view
  - Search across all accounts simultaneously
  - Ideal for comprehensive overviews and cross-account insights
  
  **Separate view benefits:**
  - Focus on specific account data without distractions
  - Maintain clear boundaries between different contexts
  - Better for account-specific tasks and workflows
  
  **Dynamic switching:**
  ```
  User: "Show me all unread emails across all accounts"
  Dume: [Unified view with data from all Gmail accounts]
  
  User: "Now show me just my work emails"
  Dume: [Switches to work account specific view]
  ```
</Accordion>
</AccordionGroup>

## Security and Privacy

### Multi-Account Security Model

<AccordionGroup>
<Accordion title="Account Isolation">
  **Maintaining separation between accounts:**
  
  **Data boundaries:**
  - Each account maintains separate authentication tokens
  - No cross-contamination of data between accounts
  - Account-specific permission scopes
  - Isolated storage and processing for each account
  
  **Privacy controls:**
  ```
  Work Account: High privacy, no personal data mixing
  Personal Account: Standard privacy, casual interaction allowed
  Client Account: Professional privacy, client-specific boundaries
  ```
  
  **Access control:**
  - User explicitly controls which accounts are accessed
  - Clear consent for cross-account operations
  - Audit logs for multi-account activities
</Accordion>

<Accordion title="Authentication Management">
  **Secure authentication across multiple accounts:**
  
  **OAuth security:**
  - Each account has independent OAuth tokens
  - Token refresh and expiration handled per account
  - No shared credentials between accounts
  - Secure token storage with account isolation
  
  **Re-authentication handling:**
  ```
  Scenario: Work Gmail token expires
  Dume: "Work Gmail authentication expired. Please re-authorize to continue accessing work emails."
  Action: Individual account re-authentication without affecting other accounts
  ```
  
  **Permission management:**
  - Account-specific permission scopes
  - Independent permission updates
  - Clear permission boundaries between accounts
</Accordion>

<Accordion title="Enterprise and Compliance">
  **Business-grade multi-account security:**
  
  **Enterprise features:**
  - Account-level audit trails
  - Compliance reporting per account
  - Role-based access controls
  - Data residency requirements per account
  
  **Compliance considerations:**
  ```
  Work Account: GDPR, SOC2, HIPAA compliance
  Personal Account: Standard privacy protections
  Client Account: Custom compliance requirements
  ```
  
  **Data handling:**
  - Account-specific data retention policies
  - Separate encryption keys per account
  - Independent backup and recovery procedures
</Accordion>

## Troubleshooting Multiple Accounts

<AccordionGroup>
<Accordion title="Connection Issues">
  **Resolving multi-account connection problems:**
  
  **Common issues:**
  - **Account confusion** - Queries accessing wrong account
  - **Authentication failures** - One account losing connection
  - **Permission conflicts** - Inconsistent permissions across accounts
  - **Sync delays** - Data not updating for specific accounts
  
  **Diagnostic steps:**
  ```
  1. Check account status in dashboard
  2. Verify account names and labels are clear
  3. Test individual account connections
  4. Review recent authentication changes
  5. Check for service provider issues
  ```
  
  **Quick fixes:**
  - **Refresh specific account** - Force reconnection for problematic account
  - **Clear account cache** - Reset account data cache
  - **Re-authenticate account** - Complete OAuth flow again
  - **Rename confusing accounts** - Update labels for clarity
</Accordion>

<Accordion title="Query Confusion">
  **When Dume accesses the wrong account:**
  
  **Prevention strategies:**
  - Use specific account names in queries
  - Set clear default account preferences
  - Provide context clues in your requests
  - Use account-specific keywords
  
  **Correction commands:**
  ```
  User: "That was from the wrong account - check my work Gmail instead"
  Dume: "Switching to Work Gmail - here are the work emails about that topic"
  
  User: "I meant my personal account, not work"
  Dume: "Corrected - searching Personal Gmail account instead"
  ```
  
  **Account specification techniques:**
  ```
  ✅ "Check my work emails for the client meeting"
  ✅ "Draft from my personal Gmail account"
  ✅ "Search my freelance account for invoice emails"
  ❌ "Check emails" (too vague)
  ❌ "Send an email" (unclear which account)
  ```
</Accordion>

<Accordion title="Performance and Sync Issues">
  **Optimizing multi-account performance:**
  
  **Sync optimization:**
  - **Staggered sync** - Accounts sync at different intervals
  - **Priority accounts** - More frequent sync for important accounts
  - **Selective sync** - Only sync relevant folders/data
  - **Background updates** - Continuous sync without user interruption
  
  **Performance tips:**
  ```
  ✅ "Check my work account for urgent emails" (specific account)
  ✅ "Show me today's emails from all accounts" (reasonable timeframe)
  ❌ "Search all accounts for everything" (too broad)
  ❌ "Show me all emails ever from all accounts" (performance heavy)
  ```
  
  **Troubleshooting slow responses:**
  1. Check individual account connection speed
  2. Reduce query scope and timeframe
  3. Test with single account queries
  4. Clear cache and refresh connections
  5. Check service provider API limits
</Accordion>
</AccordionGroup>
