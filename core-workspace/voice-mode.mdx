Voice mode opens a live, real-time spoken conversation with Dume inside the app. Open it from the voice icon next to the message box.

{/* TODO: Phase 3 screenshot — voice mode sheet with waveform and transcript */}

While it's active you'll see a waveform, a running transcript of both sides of the conversation, and controls to mute or end the call. It picks up the same context as the session you opened it from.

Voice mode is one of three ways to talk to Dume without typing, and each does something different:

| | Where it happens | What it's for |
|---|---|---|
| Voice mode | Inside the app | A live spoken conversation in place of typing |
| Microphone / dictation | Inside the message box | Speech-to-text for a single message |
| [Phone calling](/interfaces/phone) | A real phone call | Reach Dume, or have Dume reach you, without opening the app |
