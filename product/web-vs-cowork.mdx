Dume's web app and Cowork desktop app share the same interface, with a few differences:

| | Web app | Cowork desktop |
| --- | --- | --- |
| File attachments in chat | Yes | Not yet |
| Local file access (read/write your own files) | No | Yes |
| [Dume Office](/office/overview) (native Docs/Sheets/Slides/PDF editors, beta) | No | Yes |
| Browser automation (agent-browser skill) | No | Yes |
| Skill Library | No | Yes |
| Onboarding walkthrough | No | Yes |
| Desktop app settings (auto-update, tray, sleep prevention) | No | Yes |
| Local routines (run on your machine) | No | Yes |

Everything else, chat, cloud routines, integrations, MCP servers, voice mode, works the same in both. Pick web for zero-install access from any browser, or Cowork when you need Dume to touch your local files, drive a real browser session, or run local routines. See [Getting started with the web app](/product/web-app) and [Dume Cowork](/product/dume-cowork).
