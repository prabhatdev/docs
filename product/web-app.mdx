The web app at [app.dume.ai](https://app.dume.ai) gives you the same core Dume experience as the Cowork desktop app: chat, routines, integrations, MCP servers, all from any browser, no installation required. File attachments in chat are only available here, not in Cowork.

## Getting started

<Steps>
  <Step title="Sign in">
    Go to [app.dume.ai](https://app.dume.ai) and sign in or create an account.
  </Step>
